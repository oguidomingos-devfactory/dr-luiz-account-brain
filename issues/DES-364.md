- Segmentos: particulares + convênio AMHP + encaminhadores + dor crônica

- Canais: busca orgânica + encaminhamentos + social (presença zero) + Google Meu Negócio + site
- Relacionamento: pré-consulta (confiança) → consulta (experiência) → pós-consulta (follow-up)
- Receita: consultas + procedimentos + convênio + follow-up
- Recursos: expertise + clínica + rede médica + agenda + equipamentos

✅ **3 Personas criadas e mapeadas:**

1. **Julio** (Trauma Agudo) — homem 35-55, renda R$5-12k, ativo, busca solução rápida
   - Intent: "ortopedista quadril Brasília", "cirurgia quadril DF"
   - Journey: dor → Google → WhatsApp → consulta → procedimento → follow-up

2. **Maria** (Dor Crônica) — mulher 55-70, renda R$3-8k, muitas vezes convênio
   - Intent: "dor quadril", "infiltração", "especialista em dor"
   - Journey: dor crônica → busca referência → consulta → infiltração + follow-up

3. **Dr. João** (Encaminhador) — médico 45-60, cirurgião/clínico
   - Intent: especialista confiável, expertise reconhecida
   - Journey: paciente encaminhado → consulta → resultado positivo → continua referindo
